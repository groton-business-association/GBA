# Groton Business Association website

The website of the Groton Business Association (GBA), Groton, Massachusetts. It is a static site hosted on Netlify. Every change saved to the `main` branch of this repository goes live automatically within about a minute.

## Editing members: use the editing page

Open **https://groton-business-association.netlify.app/admin** and sign in with GitHub. Your GitHub account needs write access to this repository.

- **Add a member:** Members, then New Member. Fill in the form and click Save.
- **Change a member:** click the member, edit, Save.
- **Hide a member** (for example, dues not paid): turn off "Show on the website" and Save. The record is kept.
- **Delete a member for good:** open the member and choose Delete. Hiding is usually the better choice, because it keeps the record.

Each Save goes live within about a minute. You never need to touch the code to manage members.

## What is where

| Path | What it is |
|---|---|
| `members/` | One file per member. The editing page writes these. |
| `site/` | The website itself. Netlify publishes this folder. |
| `site/admin/` | The editing page (Sveltia CMS, MIT license) and its settings, `config.yml`. |
| `site/admin/config.yml` | The editing form, including the master list of categories and subcategories. |
| `site/data/members.csv`, `site/data/categories.csv` | Generated by `build.py` from the files above. Do not edit by hand. |
| `site/assets/logos/` | Member logos. Uploads from the editing page land here. |
| `build.py` | Builds the pages and the member data. Netlify runs it on every deploy. |
| `netlify.toml` | Netlify settings: build command, security headers, redirects from the old site's addresses. |

Everything in this repository is public, and so is everything in `site/` once it is live. Keep private notes, dues records and personal details out of it.

## Other changes

**Calendar events.** Not here. Edit the GBA Google Calendar. The Calendar page reads it directly.

**Add or rename a category.** Edit the `options` list under "Categories" in `site/admin/config.yml`. Write subcategories as `Main category > Subcategory`. If you rename a category, also update the members that use it.

**Change page text.** Edit the text in `build.py`, run `python3 build.py`, and commit. Do not edit the `.html` files directly, because the next build overwrites them.

**Member logos.** PNG or JPG, square or close to it, at least 256 by 256 pixels, under 2 MB, transparent or white background. Members send their own logo.

## Rules

- No payments on the site. Dues are by check.
- Keep all links relative.
- Keep the security settings in `netlify.toml` and the security policy line in `build.py`.
- The old WordPress site was hacked. Never copy code, plugins or files from it.

## Undoing a change

In Netlify, open the project, go to Deploys, pick an earlier deploy, and choose "Publish deploy." In GitHub, every save from the editing page is a commit, so any change can be reverted there.
